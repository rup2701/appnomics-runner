# Open points in the product showcase pack

These are known gaps, not mistakes. The builder records its own choices in AGENT_LOG.md.

| # | Gap | Default in this version |
| --- | --- | --- |
| 1 | Collecting emails or sign-ups | Not built. The main button is a link the owner sets. Sign-ups are an integration for a later version. |
| 2 | Sending email of any kind | Not built. |
| 3 | Payments or checkout | Not built. Pricing buttons use the main button's link. |
| 4 | An owner screen for editing the page | Not built on purpose. Changes are made by asking Scout. |
| 5 | Real images and logos | A plain labelled placeholder for the hero image. The owner sends images later. |
| 6 | Legal pages (privacy, terms, security) | Not written by the builder. The links exist in the footer and are flagged "Set your link" until the owner supplies them. |
| 7 | Visit analytics | Not built. |
| 8 | Custom domain | Not built. The site uses the address the host assigns, which the owner can change. |
| 9 | Multiple languages, A/B tests | Not built. |
| 10 | Acceptance checks as executable tests | The `verification` arrays are prose. The builder writes the Playwright checks, one per edge. |
